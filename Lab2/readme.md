# FS (File System) Node JS's Module

## Major task of FS Module

- Reading and Writing Files
  - readFile()
  - writeFile()
  - appendFile()

- Directory Management
  - mkdir()
  - rmdir()
  - rm()
  - readdir()

- Metadata/ Information
  - stat()
  - lstat()
  - fstat()

- Watching for Changes
  - watch()
  - watchFile()
  - unwatchFile()

- Streaming Large File
  - createReadStream()
  - createWriteStream()

- File Operations
  - rename()
  - truncate()
  - unlink()
  - link()
  - syslink()
